# Spotify Ad Ignorer

Spotify Ad Ignorer doesn't block Spotify ads, it ignores them by closing the application & restarting it

Spotify Ad Ignorer is for use with the windows desktop version of Spotify

## How it works

Simply run Spotify Ad Ignorer instead of Spotify, Spotify Ad Ignorer will then launch Spotify and restart it when an ad plays

If Spotify is the active application, it will instead mute Spotify until the ad has finished or the user clicks away from Spotify to trigger the restart

## Notes

If you have crossfade enabled in Spotify, it will crossfade into an ad & restart as soon as (or just before) the ad starts playing, this can cause a sudden cut-off of the last few seconds of music (UPDATE: Spotify seems to have fixed this)

All config settings are stored in the registry `HKCU\Software\Spotify Ad Ignorer`
